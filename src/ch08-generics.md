# 第 8 章 泛型与单态化

在 Ayanami 中，泛型是一种强大的抽象机制，允许我们编写适用于多种类型的代码。通过使用泛型，可以避免重复实现相同逻辑的不同版本，从而提高代码的复用性和类型安全性。

## 泛型函数

泛型函数是使用类型参数定义的函数。这些类型参数在调用时由编译器自动推断。例如，一个简单的恒等函数 `identity` 可以写成如下形式：

```ayanami
fn identity[T](T a) -> T { return a; }
```

这个函数接受一个类型为 `T` 的参数 `a`，并返回相同类型的值。在调用时，编译器会根据传入的实际参数自动确定 `T` 是什么类型。

我们来看一个具体的例子：

```ayanami
fn main() -> int {
    a = identity(42)
    b = identity(3.14)
    return a + 62 - 3
}
```

在这个例子中，第一次调用 `identity(42)` 时，编译器推断出 `T` 是 `int` 类型；第二次调用 `identity(3.14)` 时，`T` 被推断为 `float`。尽管函数体完全相同，但编译器会为每种类型生成一份独立的代码。

## 接口约束

泛型函数还可以通过接口来限制其参数必须满足某些条件。例如，如果我们要实现一个比较两个值并返回较大者的函数，可以使用 `Ord` 接口作为约束：

```ayanami
fn max[T: Ord](T a, T b) -> T {
    if a > b { return a; }
    return b;
}
```

这里的 `T: Ord` 表示类型 `T` 必须实现了 `Ord` 接口。该接口通常包含比较操作符如 `<`, `>`, `<=`, `>=` 等。

调用时，编译器会确保传入的参数类型确实实现了 `Ord` 接口：

```ayanami
fn main() -> int {
    c = max(10, 20)
    return c
}
```

在这个例子中，`max(10, 20)` 被推断为 `max[int](int, int)`，因为整数类型 `int` 实现了 `Ord` 接口。如果尝试传入不支持比较操作的类型（比如结构体），编译器将报错。

## 泛型结构体

泛型不仅适用于函数，也适用于结构体。我们可以定义一个通用的容器结构体，例如：

```ayanami
struct Box[T] { T value }
```

这个 `Box` 结构体可以存储任意类型的值，并且在使用时会根据具体类型生成对应的代码。

此外，标准库中已经提供了许多泛型结构体的例子，比如 `ArrayList[T]`（动态数组，元素类型无约束）：

```ayanami
import "arraylist"
fn main() -> int {
    list = ArrayList::new[int]()   // 显式泛型实参
    list.push(42)
    return list.len()
}
```

### 显式泛型实参与推断

命名空间函数可以用显式泛型实参调用：`ns.fn[T](args)`。省略时，编译器会根据后续用法推断类型：

```ayanami
a = ArrayList::new()      // T 暂未确定
a.push(7)                 // 由 push 推断 T = int

b = ArrayList::with_capacity[String](8)   // 显式指定
```

标准库构造函数都采用这种形式，详见第 11 章与附录 A。

## 单态化

Ayanami 的泛型机制采用的是单态化（monomorphization）策略。这意味着编译器会在编译阶段为每一个具体的类型生成一份对应的函数或结构体实现。例如，当我们调用 `identity(42)` 和 `identity(3.14)` 时，编译器会分别生成两个版本的 `identity` 函数：

```ayanami
fn identity_int(int a) -> int { return a; }
fn identity_float(float a) -> float { return a; }
```

这种机制的优点在于运行时没有额外开销，因为所有类型检查和分发都在编译期完成。缺点则是可能导致生成的代码体积较大。

相比之下，第 7 章中介绍的接口动态派发则是在运行时根据对象的实际类型进行方法调用，虽然灵活性更高，但会带来一定的性能损耗。

## 类型推断与泛型

在泛型函数的调用点上，编译器能够根据传入的参数自动推断出类型参数的具体值。例如：

```ayanami
fn identity[T](T a) -> T { return a; }

fn main() -> int {
    x = identity(42)
    return x
}
```

这里 `identity(42)` 中的 `42` 是一个整数字面量，因此编译器推断出 `T = int`。如果传入的是浮点数，则会自动推断为 `float`。

这种类型推断机制使得泛型代码既灵活又易于使用，开发者无需显式指定类型参数即可编写通用函数。

## 总结

本章介绍了 Ayanami 中的泛型系统及其核心概念——单态化。通过泛型函数和结构体，我们可以写出适用于多种类型的代码；而接口约束则保证了这些泛型在特定场景下的可用性。编译器通过对类型参数进行推断并生成具体实现的方式，实现了高效且安全的泛型支持。
