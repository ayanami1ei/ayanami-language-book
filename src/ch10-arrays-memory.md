# 第 10 章 数组与内存管理

在 Ayanami 中，数组是一种非常基础且重要的数据结构。它既可以表示动态大小的堆分配数组，也可以是定长数组。我们先从最简单的数组字面量开始。

```ayanami
a = [10, 20, 30]
```

这行代码创建了一个拥有三个整数元素的数组，并将其赋值给变量 `a`。你可以通过索引访问或修改数组中的元素：

```ayanami
a[1] = 21
v = a[1]  // v 等于 21
```

这种语法与大多数语言一致，但需要注意的是，Ayanami 中的数组是拥有堆缓冲区的。这意味着当你将一个数组赋值给另一个变量时，它会移动（move）整个数组内容，而不是仅仅复制引用。

```ayanami
q = [1, 2]
s = q   // 这里 q 被移动给了 s，q 不再可用
```

一旦数组被移动，原变量就无法再使用。这种设计有助于避免内存错误和悬空指针问题。当数组离开其作用域时，系统会自动递归释放它所占用的堆内存，无需手动调用 `free`。

```ayanami
fn make() -> int {
    q = [1, 2]
    s = [3, 4]
    return q[0] + s[1]
}
```

上面这段代码展示了数组如何在函数中被创建并使用。注意，虽然 `q` 和 `s` 是局部变量，在函数结束时它们会自动释放内存。

对于定长数组，你可以使用语法 `[T; n]` 来声明，其中 `n` 可以是一个运行期变量：

```ayanami
n = 5
buf = [char; n]
```

数组一旦创建，长度就固定为 `n`；`n` 本身可以在运行时计算得出。它们同样拥有堆缓冲区，并遵循与动态数组相同的内存管理规则。

如果你希望避免移动数组，可以使用借用语法传递数组引用：

```ayanami
fn process_array(ref [int] arr) -> int {
    return arr[0]
}
```

这里参数 `arr` 是一个对 `[int]` 类型的引用。这样你就可以在不移动原数组的情况下读取或处理它。

Ayanami 中的字符串本质上是一个结构体，包含字符数组和长度信息：

```ayanami
struct String {
    [char] data
    int len
}
```

因此，`String` 实际上就是 `[char]` 加上一个长度字段。你可以通过 `to_string()` 方法将其他类型转换为字符串，也可以使用拼接操作符进行连接：

```ayanami
s = "Hello"
t = s + " World"
```

为了验证内存是否正确释放，我们可以借助内置函数 `__ayanami_live_allocs()` 来检查当前活跃的分配数量。如果程序结束时该值仍大于零，则说明存在内存泄漏。

下面是一个完整的示例程序：

```ayanami
extern "C" fn __ayanami_live_allocs() -> int;

fn make() -> int {
    q = [1, 2]
    s = [3, 4]
    return q[0] + s[1]
}

fn main() -> int {
    a = [10, 20, 30]
    a[1] = 21
    v = make()
    return a[1] - 21 + __ayanami_live_allocs()
}
```

在这个例子中，`main()` 函数创建了一个数组 `a` 并修改了它的元素。随后调用 `make()` 函数，该函数内部也创建并使用了两个数组。最后通过 `__ayanami_live_allocs()` 检查是否还有未释放的内存块。

数组元素可以是任意类型：字符串、结构体、枚举都行。例如：

```ayanami
import "io"
import "string"

struct Point {
    int x
    int y
}

fn main() -> int {
    names = ["Alice", "Bob"]
    println(names[0])   // Alice

    pts = [Point { x = 1, y = 2 }, Point { x = 3, y = 4 }]
    println(pts[1].x)   // 3
    return 0
}
```

聚合元素（结构体/枚举）会按 LLVM 布局分配；离开作用域时，数组中的元素会被递归释放。

下标可以是任意整数类型（`int` / `usize` / `u8` / `i32` …），编译器统一按寻址宽度处理：

```ayanami
a = [10, 20, 30]
i = 1usize
a[i] = 21          // 也可以写 a[1u8] 等
```
