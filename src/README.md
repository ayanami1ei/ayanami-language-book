# 关于本书

Ayanami 是一门自带 LLVM 后端的编译型语言：单二进制分发、开箱即用，支持类型推断、
泛型单态化、接口动态派发、所有权与借用检查，以及一套可被编译器验证的标注系统。

本书的目标读者是**有基本编程概念的初学者**，以及想了解 Ayanami 设计取舍的开发者。
全书从安装和第一个程序开始，逐步讲到类型系统、所有权、标准库、标注系统，最后完成
一个综合项目。每章都有可直接运行的示例，示例以主仓库
[`example/`](https://github.com/ayanami1ei/Ayanami-language/tree/rust/example) 中的
端到端用例为准。

## 为什么是 Ayanami

- **单二进制**：编译器自带 LLVM，不需要系统预装 LLVM；下载解压即可使用。
- **静态类型 + 类型推断**：`x = 42` 就能推断出 `int`，同时保留完整的编译期检查。
- **默认所有权、显式借用**：非 Copy 值赋值即移动，`ref` / `ref mut` 表示借用，
  借用检查器（NLL 风格）在最后一次使用后自动释放借用。
- **标注驱动**：`#[inline]`、`#[cfg]`、`#[requires]`、`#[follow_with]` 等标注不是注释，
  而是被编译器验证、参与代码生成与优化的契约。
- **可读的编译管线**：源码 → Lexer → Parser → HIR → MIR → LIR → LLVM IR → 可执行文件。

## 本书结构

- **第 1~2 章**：安装、工具链，以及一个完整的猜数字游戏。
- **第 3~4 章**：变量、类型、运算符、控制流、函数与命名空间。
- **第 5~8 章**：结构体、枚举、接口、泛型——用类型组织程序。
- **第 9~10 章**：所有权、借用与数组内存模型。
- **第 11~12 章**：标准库与错误处理。
- **第 13~15 章**：标注系统、生命周期注解、FFI / 汇编 / 宏。
- **第 16~18 章**：工具链、测试，以及一个综合项目。

## 阅读约定

- 代码块标注为 `ayanami`，可以直接保存为 `.aya` 文件运行。
- 命令行以 `$` 开头；`ayanami` 指编译器可执行文件。
- 参数顺序是 **类型 名称**（如 `fn add(int a, int b) -> int`），与 C 系语言相反，请留意。
- 教程不追求覆盖每个边角，而是把主线讲清楚；语言细节以
  [主仓库 README](https://github.com/ayanami1ei/Ayanami-language/blob/rust/README.md)
  和 `std/README.md` 为准。
